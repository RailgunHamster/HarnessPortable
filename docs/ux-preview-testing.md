# UX 测试候选 · 2026-10-13

这次按确认的预览方向实现：PC 使用多服务器、标签和分屏；手机使用单窗口、单服务。当前候选版本为 2.7.0，尚未正式发布，也没有更新线上安装包或更新源。

## 已实现

- 桌面连接库：可折叠侧栏，搜索、常用、最近、分组，统一编辑与更多操作。再次打开同一连接聚焦已有标签，右键复制可多开。
- 桌面工作区：自动保存标签、分屏比例与选中位置；命名预设独立保存。启动默认恢复工作区并暂停 SSH，设置可开启自动重连。停止 SSH 保留标签。
- 设置：桌面独立分类窗口，手机独立页面。外观等偏好即时保存；更新源明确保存、撤销，检查更新使用已保存的地址。导出配置不包含凭据。
- 手机导航：返回列表或进入设置保持当前连接和网页状态；切换服务先确认，确认或主动断开才释放旧网页。默认显示导航，可开启服务全屏菜单。
- 性能：桌面快照延迟合并写入，暂停的 SSH 标签延迟创建浏览器；手机最多一个当前网页实例，列表使用懒加载，无持续动画和模糊。

## 试用建议

Windows 解压测试 ZIP，运行 `HarnessPortable.exe`。使用现有配置时，先退出旧进程再启动测试包。默认数据目录仍为 `%APPDATA%\HarnessPortable`。

Android APK 使用现有正式签名和应用 ID，可覆盖安装并保留配置。应用内显示 2.7.0（versionCode 21）。这次测试包没有进入在线更新源。

1. Windows：添加多个服务器与直连，收藏、分组、搜索，收起再展开侧栏；确认各连接的状态与更多菜单可见。
2. Windows：打开多个标签，拖动上下左右分屏，复制、重命名，窄窗格拖拽检查提示完整；关闭再打开，确认标签、比例和选中位置恢复。
3. Windows：停止一个 SSH，确认标签仍在、其他服务正常；点击重连。检查命名预设和自动快照互不覆盖。
4. 手机：连接一个实际服务，在网页内操作后返回列表、进入设置、继续使用，确认连接和网页状态仍在。
5. 手机：打开第二个服务，分别尝试取消和确认；取消保留旧服务，确认切换到新服务。主动断开后没有“当前服务”。
6. 设置：切换深浅色；修改更新源地址、切换槽位、撤销，再明确保存；确认草稿不会影响未保存前的更新检查。手机可试服务全屏、旋转和返回。

反馈时注明平台、操作步骤、预期与实际效果；视觉问题可附截图，拖拽问题可附短录屏。

## 验证记录

- Windows：175 项测试全部通过；实际 WPF 主窗口与设置分类构造、布局导出、900 像素窄窗口检查通过。更新源草稿切换和撤销检查通过。
- Android：编译与 lint 通过；隔离模拟器验证列表与设置，网页在返回、设置之间保留实例和页面状态，取消切换保留旧服务，确认切换及断开释放旧实例。
- macOS：37 项测试、arm64 与 x86_64 通用构建和 DMG 打包通过，见 [CI 验证](https://github.com/RailgunHamster/HarnessPortable/actions/runs/38275005019)。尚未在真实 Mac 上完成完整鼠标交互试用。
- 模拟器的网页生命周期验证使用本地 HTTP 测试服务；实际服务器的 SSH 认证与网页交互仍需本次试用确认。
